# AI usage disclosure

This project was built with substantial help from an AI coding assistant.

**What the AI did**
- Generated large portions of the HTML, CSS, and JavaScript, including the `.soe`
  parser/serializer, the built-in PDF writer, and the UI.
- Helped design the Spanish translation workflow and the terminology glossary.

**What the human author did**
- Defined the requirements, scope, and design decisions.
- Reviewed, corrected, and edited the generated code.
- Tested the app against real files and across browsers and devices.
- Made all decisions about what to keep, change, or discard.

**Independence**
The AI implemented the `.soe` format from its structure. No source code or assets from
any other application were copied, decompiled into this project, or redistributed here.
