StepSheet - browser extension (Chrome or Edge)

Install (one time):
1. Keep this folder somewhere permanent, e.g. Documents\StepSheet\Extension.
   The browser runs the extension from this folder, so don't delete or move it.
2. Edge:   go to edge://extensions   Chrome: go to chrome://extensions
3. Turn on "Developer mode" (left side in Edge, top right in Chrome).
4. Click "Load unpacked" and pick this folder (the one with manifest.json in it).
5. Click the puzzle-piece icon in the toolbar and pin StepSheet.

Use: click the StepSheet toolbar button. It opens the editor in a tab
(or switches to it if it's already open). Everything works offline and your
files stay on your computer.

Updating: replace the files in this folder, then click the reload arrow on the
extension's card in edge://extensions.

If "Developer mode" or "Load unpacked" is greyed out, your company blocks
side-loaded extensions; use StepSheet.html instead.
